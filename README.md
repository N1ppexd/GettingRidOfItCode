# GettingRidOfItCode
The code for 2023 game getting rid of it

This was a game project that we made in 2023 in Pelifarmi.
I wrote the majority of the code for this project, and this repository showcases my code contribution back then.

We had 4 weeks to create this game, and I'm proud of what I was able to accomplish during the short period of time we had

# About the Game

**Getting rid of it** Is a game where you have a **dead body** in your living room and you need to figure out how to **get rid of it without getting caught**. You can **chop the body** into pieces, **cook meatballs**, flush parts down the toilet and throw parts in the trash. Your neighbours must not get suspicious.

The link for the playable version of the game is on itch.io : [Playable Version](https://n1ppe.itch.io/getting-rid-of-it)
